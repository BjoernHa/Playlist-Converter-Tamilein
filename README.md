# Tamilein — Downloads

**Playlists frei übertragen** zwischen Spotify, Deezer, TIDAL, YouTube Music und
SoundCloud. Ohne Limit, ohne Konto bei einem Zwischendienst — alles läuft lokal
auf deinem eigenen Gerät.

Dieses Repository enthält **nur die fertigen Installationsdateien**. Der
Quellcode wird hier nicht veröffentlicht.

## Herunterladen

Die Dateien liegen unter **[Releases](../../releases/latest)** — das ist ein
eigener Bereich, nicht die Dateiliste oben. Am Rechner steht er rechts neben
der Dateiliste, am Smartphone ganz unten, hinter allen Dateien.

| System | Datei | Installieren |
|---|---|---|
| Linux Mint / Ubuntu / Debian | `tamilein_<Fassung>_all.deb` | Doppelklick → „Paket installieren“ |
| Windows | `Tamilein-<Fassung>-Setup.exe` | Doppelklick, kein Administrator nötig |
| Android | `tamilein-<Fassung>.apk` | aufs Telefon kopieren, antippen, Installation aus unbekannter Quelle erlauben |

Jedes der drei Programme läuft **allein** auf dem jeweiligen Gerät. Es muss
nirgends ein anderer Rechner an sein.

## Aktualisieren

Im Programm selbst: **Hilfe → Aktualisieren → „Nach Updates suchen“**.
Dafür ist keine Anmeldung nötig.

## Lizenz und Quellcode

Tamilein steht unter der **GPL-3.0-or-later**. Wer eines der Programme von hier
bekommt, hat damit Anspruch auf den zugehörigen Quellcode; er wird auf Anfrage
über ein Issue in diesem Repository herausgegeben.
